## 📖 درباره پروژه

**سامانه مدیریت امور دانشگاهی (LMS)** یک پروژه دانشگاهی است که با هدف حل مشکل پراکندگی منابع آموزشی و نبود یک بستر یکپارچه برای تعامل دانشجو و استاد طراحی شده است.

در این سامانه، استادان می‌توانند کورس‌های آموزشی خود را ایجاد کرده و فایل‌های آموزشی را بارگذاری کنند؛ دانشجویان نیز می‌توانند به این کورس‌ها دسترسی داشته باشند و از کتابخانه مجازی برای جستجو و دانلود منابع استفاده کنند.

### 🎯 مسئله‌ای که حل می‌کند

- پراکندگی جزوه‌ها و منابع آموزشی در سامانه‌های مختلف
- اتلاف وقت دانشجو برای دریافت یک منبع ساده
- نبود بستر یکپارچه برای ارتباط استاد و دانشجو
- عدم دسترسی آسان به منابع کتابخانه‌ای

## ✨ قابلیت‌های اصلی (MVP)

| قابلیت | توضیح |
|--------|-------|
| 🔐 **ورود و احراز هویت** | ورود با نام کاربری و رمز عبور، تشخیص نقش دانشجو/استاد و هدایت به داشبورد مناسب |
| 📚 **مدیریت کورس توسط استاد** | ایجاد کورس، ویرایش اطلاعات و بارگذاری فایل منابع آموزشی |
| 📥 **دسترسی دانشجو به منابع** | مشاهده کورس‌های ثبت‌نام‌شده و دانلود فایل‌های آموزشی |
| 🏛️ **کتابخانه مجازی** | جستجو بر اساس عنوان/نویسنده، مشاهده جزئیات و دانلود منبع |

### 🚀 اهداف تکمیلی

- 🔔 سیستم اعلان‌ها (اطلاع‌رسانی هنگام بارگذاری محتوای جدید)
- 👥 مدیریت کاربران توسط مدیر سامانه

## ⚙️ نصب و راه‌اندازی

### پیش‌نیازها

- Python 3.10 یا بالاتر
- pip
- Git

### مراحل نصب

۱. **کلون کردن مخزن:**

```bash
git clone https://github.com/USERNAME/lms-project.git
cd lms-project
```

۲. **ایجاد محیط مجازی و فعال‌سازی آن:**

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate
```

۳. **نصب وابستگی‌ها:**

```bash
pip install -r requirements.txt
```

۴. **اعمال مهاجرت‌های پایگاه داده:**

```bash
python manage.py makemigrations
python manage.py migrate
```

۵. **ایجاد کاربر مدیر (اختیاری):**

```bash
python manage.py createsuperuser
```

۶. **اجرای سرور توسعه:**

```bash
python manage.py runserver
```

۷. **باز کردن مرورگر:**

به آدرس [http://127.0.0.1:8000](http://127.0.0.1:8000) بروید.
